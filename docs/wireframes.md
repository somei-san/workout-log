# ワイヤーフレーム

用語と仕様は [ux-design.md](ux-design.md) を参照。ここでは図の読み方だけを注記する。

## 種目グリッド(ホーム)

```
┌─────────────────────────────┐
│ [経過日数|部位]        [＋] │
├─────────────────────────────┤
│ 背中                        │
│ ▌ラットプル ▌デッドリフト ▌ルーマ…│ ← 種目名(左端の帯が部位の色)
│  3日前 10/14  3日前 10/14  7日前 10/10│ ← 経過日数・最終実施日
│ 胸                          │
│ ▌ベンチ    ▌ポーズベンチ ▌インクライン│
│  3日前 10/14  11日前 10/06 11日前 10/06│
│ 脚                          │
│ ▌レッグプレス …             │
├─────────────────────────────┤
│ 種目   履歴   分析   設定    │
└─────────────────────────────┘
```

- 図は「部位」で並べた状態。
- 「ベンチ」は、実際には「ベンチプレス」。幅の都合で省略している。

## 種目の記録

```
┌─────────────────────────────┐
│ ‹ 戻る     デッドリフト   🏆│
├─────────────────────────────┤
│ 前回  135kg×5 / 125kg×5     │
│                             │
│ 1  ↪[ 135.0 ]kg ↪[ 5 ]回 ✓ │
│    1RM 151.9kg    RPE ↪[ 9 ]│
│    メモ ↪[                ]│
│ ─────────────────────────── │
│ 2  ↪[ 135.0 ]kg ↪[ 5 ]回  ○ │
│    RPE ↪[   ]               │
│    メモ ↪[                ]│
│ ─────────────────────────── │
│                             │
│            [＋ セット追加]  │
├─────────────────────────────┤
│ 種目   履歴   分析   設定    │
└─────────────────────────────┘
```

- 太字は入力済み、薄字は初期値(未確認の値)。図では 2 行目の「135.0」と「5」が薄字。
- ✓ は完了済み、○ は未完了。
- 各値の右の ✕(値を消す)と、行の左スワイプ(削除)は、図では省略している。
