# ワイヤーフレーム

用語と仕様は [ux-design.md](ux-design.md) を参照。ここでは図の読み方だけを注記する。

## 種目グリッド(ホーム)

```
┌───────────────────────────────────────┐
│ [すべて|部位][↕]              [⚙][＋] │
├───────────────────────────────────────┤
│ 胸                                    │
│ ●ポーズ      ●インクライ   ●ベンチ    │ ← ● は部位のアイコン(部位の色)
│  ベンチ       ンDB          プレス    │ ← 名前の続き
│ 11日前 10/06 11日前 10/06  3日前 10/14│ ← 経過日数・最終実施日
│ 背中                                  │
│ ●ルーマニア  ●ラットプル   ●デッド    │
│  ンデッド     ダウン        リフト    │
│  7日前 10/10  3日前 10/14  3日前 10/14│
│ 腕                                    │
│ ●アーム      ●トライ                  │
│  カール       セップス                │
│ 16日前 10/01  7日前 10/10             │
│ 足                                    │
│ ●レッグ                               │
│  プレス                               │
│  7日前 10/10                          │
│                                       │
│ ▸ 非表示の種目(1)                     │ ← タップで開く
└───────────────────────────────────────┘
```

- 図は「部位」の見方で、並べ方が初期値(経過日数：降順)の状態。
- ↕ は並べ替えのボタン、⚙ は設定を開く歯車のアイコン。
- 図の種目名は、どれも 1 行に入らず 2 行目に折り返して出ている。

## 種目の履歴

```
┌─────────────────────────────┐
│ ‹         デッドリフト 📈 ＋ ⚙│
├─────────────────────────────┤
│ ボリューム / 推定 1RM / 最大重量(kg)│
│ 1300 / 151.9 / 135.0       2026/10/14 ›│
│ 1192.5 / 149.1 / 132.5  📝 2026/10/10 ›│ ← 📝 はメモのある記録
│ 1170 / 146.3 / 130.0       2026/10/06 ›│
│ …                           │
└─────────────────────────────┘
```

- 📈 はグラフのボタン(分析を開く)、＋ は新しい 1 回の記録を作るボタン、⚙ は種目の設定を開く歯車のアイコン。
- 図は、設定の表示項目が初期値(ボリューム、推定 1RM、最大重量を表示)の状態。

## 1 回の記録の削除

```
左スワイプ                      長押し
┌──────────────────────────┐   ┌──────────────────────────┐
│ 1300 / … 2026/10/14 ›    │   │ (種目の履歴を暗くして背景)│
│ …132.5 2026/10/10│ 削除 │   ├──────────────────────────┤
│ 1170 / … 2026/10/06 ›    │   │  2026/10/10(土) の記録    │
└──────────────────────────┘   │ [         削除         ] │ ← 赤字
                               │ [       キャンセル      ] │
                               └──────────────────────────┘
            どちらの「削除」も、次の確認を出す
          ┌──────────────────────────────────┐
          │   2026/10/10(土) の記録を削除     │
          │ セット 2 個とメモが消えます。     │
          │ 元に戻せません。                  │
          │ [          記録を削除          ] │ ← 赤字
          │ [          キャンセル          ] │
          └──────────────────────────────────┘
```

- 左スワイプの図は、行が左にずれて、右から赤い「削除」が出た状態。

## 種目の記録(編集モード)

```
┌─────────────────────────────┐
│ ‹          デッドリフト      │
│       ( 2026/10/17(土) ▾ )   │ ← 押すと日付と時刻を変える
├─────────────────────────────┤
│ 前回  135kg×5 / 125kg×5     │
│ ─────────────────────────── │
│ 1   [ 135.0 ]kg   [ 5 ]回   │
│    1RM 151.9kg     RPE [ 9 ]│
│ ─────────────────────────── │
│ 2   [ 135.0 ]kg   [ 5 ]回   │
│    1RM 151.9kg     RPE [   ]│
│ ─────────────────────────── │
│                             │
│            (＋)             │ ← 行を足すボタン
│                             │
│ メモ [                     ]│ ← 1 回の記録のメモ
└─────────────────────────────┘
```

- 図は、今日の記録で 2 セット目を足した直後の状態。2 行目の「135.0」と「5」は、1 セット目から入った初期値。強度は空欄。
- 図は、設定で強度に RPE を選んだ状態。
- 行の左スワイプと長押しのメニュー(削除)は、図では省略している。左スワイプの見た目は「1 回の記録の削除」と同じ。長押しのメニューは見出しが「2 セット目」の形になり、「削除」でそのまま消える。
- wireframes.html では、左スワイプは 2c の図だけで、動くのは長押しだけ。

## 種目の記録(新しい 1 回の記録の空の行)

```
┌─────────────────────────────┐
│ ‹          デッドリフト      │
│       ( 2026/10/17(土) ▾ )   │
├─────────────────────────────┤
│ 前回  135kg×5 / 125kg×5     │
│ 1   [   –   ]kg   [ – ]回   │ ← 空の行。– は未入力
│    1RM –           RPE [   ]│
│ 2   [   –   ]kg   [ – ]回   │
│ 3   [   –   ]kg   [ – ]回   │
│            (＋)             │
│ メモ [                     ]│
└─────────────────────────────┘
```

- 図は、最初に並べるセット数を 3 にした種目で、新しい 1 回の記録を開いた直後の状態。2・3 行目の下段は省略している。
- wireframes.html では、空の行を捨てる動き(保存しないこと)は再現していない。
